# Photos à fournir

Fichier généré par `scripts/manques.mjs` à chaque `npm run build`, à partir des champs `photos[]` (statut `replace` ou `missing`) des données. Base : 01-audit-design §4.

Format attendu pour chaque prise de vue :

- paysage 3:2, 2 400 px de large au minimum, plus une version verticale 4:5 pour le mobile ;
- JPEG en qualité maximale ou RAW, sans filtre, horizon droit, saturation d'origine ;
- vraie photo prise dans la région, jamais un scan de brochure, une photo de banque ou une image générée ;
- pas de photo de l'équipe (décision du client), autorisation écrite de toute personne reconnaissable ;
- une photo ne sert qu'à un seul produit ; l'image de partage 1200×630 de chaque page est tirée de ces photos.

50 prises de vue sur 21 pages. Faute de vraie photo, la page en affiche moins (00-BRIEF §7).
